about=English
    Navigate a vector layer by a chosen sort field in ascending or descending order. Select and zoom to each feature; use First/Previous/Next/Last, exact-value search, an expression filter, a captured selection scope, or Pick from map.
    Alt+Left/Right/Home/End shortcuts are opt-in. Disable FeatureNavEd before enabling them to avoid conflicts. Navigation activates its layer so Alt+number presets target the same layer.
    Open Edit chosen fields to display and edit only the fields you choose. The editor captures its selected feature IDs when opened. Each field has an explicit Change checkbox, so mixed values and unchosen fields are not overwritten accidentally. Apply form edits and Undo operate on the layer edit buffer.
    Toggle Apply Alt+1-9 immediately: on applies to the edit buffer; off stages values in memory for Apply pending shortcuts. Staged targets are captured when the shortcut is pressed and do not change with later selections. Pending values can be previewed, undone or discarded. No operation automatically saves the data file.
    QGIS 4.2+ in the 4.x series. Tested with isolated memory layers on Windows, QGIS 4.2.2. QGIS 3.x is unsupported; Linux/macOS execution has not been verified. English interface, English/Korean documentation. No external packages or network access are required for core features. GPL-3.0-or-later. Navigation design credits: FeatureNavEd by Irene Jaya, MIT license.

    한국어
    필드별 오름차순·내림차순 정렬에 따라 객체를 하나씩 선택하고 확대합니다. 처음·이전·다음·마지막 이동, 필드값 검색, 표현식 필터, 선택 객체 범위 고정, 지도에서 객체 찍기를 지원합니다.
    Alt+좌우/Home/End 탐색 단축키는 직접 활성화합니다. 충돌을 피하려면 FeatureNavEd를 먼저 비활성화하세요. 탐색할 때 해당 레이어를 활성화하여 Alt+숫자 입력 대상과 일치시킵니다.
    Edit chosen fields에서 원하는 필드만 표시·편집할 수 있습니다. 창을 열 때 선택 객체를 고정하며, Change를 체크한 필드만 Apply form edits로 적용합니다. Undo 버튼을 제공합니다.
    Apply Alt+1-9 immediately를 켜면 레이어 편집 상태에 즉시 적용합니다. 끄면 메모리에 대기시킨 후 Apply pending shortcuts로 적용합니다. 단축키를 누른 시점의 대상 객체를 고정하며, 미리보기·실행 취소·대기값 삭제를 지원합니다. 실제 데이터 파일은 자동 저장하지 않습니다.
    QGIS 4.2 이상, 4.x 계열을 지원합니다. Windows의 QGIS 4.2.2에서 독립 메모리 레이어 테스트를 수행했습니다. QGIS 3.x는 지원하지 않으며 Linux/macOS 실제 실행은 미검증입니다. 화면은 영어, 문서는 영어·한국어입니다.
