    지정 레이어를 탐색·편집하며 프리셋 단축키, 필드 잠금, 객체 Undo와 수동 저장을 제공합니다.
about=English
    Quick Field Keys 2.0.0 runs entirely in Python. The installation ZIP contains no plugin-owned native binaries and loads no Rust extension or DLL. No extra packages or accounts are required.
    Choose a target layer in the panel, configure field/value presets and select features. Alt+1-9 applies presets to the edit buffer immediately. No selection means no changes. Activating another layer does not retarget writes. Invalid or removed targets never fall back to another layer.
    The preset button, field visibility, Save, feature Undo and settings share one row. Immediate-mode checkboxes and the mode-toggle shortcut are removed. Change or clear action keys in settings; conflicting assignments are rejected without changing other QGIS shortcuts.
    Navigate by sort order, expression filter or a captured selection. Filters are evaluated on explicit refresh, not on edits or Undo. Alt+Left/Right/Home/End navigates; Alt+Backspace restores the previous view; Alt+Up/Down cycles whole saved map themes while the panel is visible. Themes retain the designated target and unsaved edits.
    Field locks block this plugin's writes, not other QGIS tools. Drafts keep their original targets. Navigation applies valid drafts to the edit buffer; invalid values, locks and failed writes keep drafts and block movement. Use Set NULL for NULL. Primary keys, joined fields and expression fields are excluded from writes.
    Save commits ALL unsaved edits in the designated layer, including edits from other tools. There is no automatic file save. Failed commits retain the buffer. Feature Undo protects external changes and cannot restore saved edits. History holds up to 200 groups in the current session. Restarting discards unapplied inputs, pending values and feature Undo history.
    Supports QGIS 3.44 LTR and QGIS 4.2+ in the 4.x series. Python 2.0.0 regression tests run on Windows QGIS 4.2.3 / Qt 6.11, including isolated widget/lifecycle checks and temporary GeoPackage Save/reopen. QGIS 3.44, Linux/macOS, physical keyboard use and Plugin Manager installation are not verified for this release. See CHANGELOG.md for earlier test records. Restart QGIS after updating.
    GPL-3.0-or-later. Navigation design draws on Irene Jaya's MIT-licensed FeatureNavEd; attribution is included in LICENSE.FeatureNavEd.

    한국어
    2.0.0은 Python 단독으로 실행합니다. 플러그인 자체의 Rust 확장·DLL을 불러오지 않으며 설치 ZIP에도 포함하지 않습니다. 별도 패키지나 계정은 필요하지 않습니다.
    패널에서 입력 레이어와 프리셋을 지정하고 객체를 선택합니다. 기본 Alt+1~9는 편집 버퍼에 즉시 적용하며 선택이 없으면 쓰지 않습니다. 다른 레이어를 활성화해도 입력 대상은 유지합니다. 지정 대상이 없거나 삭제되면 다른 레이어에 대신 쓰지 않습니다.
    프리셋·눈·저장·객체 Undo·설정을 한 줄에 배치했습니다. 즉시 적용 체크박스와 모드 전환 단축키 항목은 제거했습니다. 설정에서 단축키를 변경·해제하며 중복·외부 충돌을 검사합니다.
    정렬·표현식 필터·고정 선택 범위로 탐색합니다. 필터는 명시적 새로고침 때 평가합니다. Alt+좌우/Home/End로 이동하고 Alt+Backspace로 직전 화면을 복원합니다. Alt+Up/Down은 패널이 보일 때 저장된 지도 테마 전체를 전환하며 지정 대상과 미저장 편집을 유지합니다.
    잠금은 이 플러그인의 쓰기만 막습니다. 초안은 원래 대상을 유지하며 이동 전에 편집 버퍼에 반영합니다. 잘못된 값·잠금·쓰기 실패는 입력을 보존하고 이동을 막습니다. NULL은 Set NULL로 지정합니다. 기본키·조인·표현식 필드에는 쓰지 않습니다.
    Save는 다른 도구의 편집을 포함해 지정 레이어의 모든 미저장 편집을 저장합니다. 파일 자동 저장은 없습니다. 저장 실패 시 버퍼를 유지합니다. 객체 Undo는 외부 변경을 보호하며 저장한 편집은 복원하지 못합니다. 현재 세션의 최근 200묶음을 보관합니다. 재시작하면 미적용 입력·대기값·객체 Undo 이력은 사라집니다.
    Windows QGIS 4.2.3 / Qt 6.11에서 Python 회귀시험, 격리된 위젯·수명주기 검사와 임시 GeoPackage 저장·재열기를 확인했습니다. 이번 버전의 QGIS 3.44·Linux/macOS·물리 키보드·Plugin Manager 설치는 미검증입니다. 과거 검증 기록은 CHANGELOG.md에 있습니다. 업데이트 후 QGIS를 재시작하세요.
